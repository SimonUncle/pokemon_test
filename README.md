# 포켓몬스터 Yellow 버전 클론

브라우저에서 즐기는 포켓몬스터 Yellow 버전 게임!

## 게임 특징

- 🎮 **클래식 포켓몬 경험**: 픽셀 아트 스타일의 레트로 게임
- ⚡ **피카츄와 함께**: 피카츄가 플레이어를 따라다닙니다!
- 🌿 **야생 포켓몬 조우**: 긴 풀을 걸어다니며 야생 포켓몬을 만나세요
- ⚔️ **턴제 배틀 시스템**: 원작처럼 전략적인 배틀
- 🗺️ **탐험 가능한 맵**: 마을, 길, 숲 등 다양한 지형

## 게임 방법

### 시작하기

1. `index.html` 파일을 웹 브라우저에서 엽니다
2. 게임이 자동으로 시작됩니다!

### 조작법

- **이동**: 화살표 키 또는 `W`, `A`, `S`, `D` 키
- **긴 풀**: 진한 초록색 풀을 걸어다니면 야생 포켓몬을 만날 수 있습니다

### 배틀

긴 풀에서 야생 포켓몬을 만나면 배틀이 시작됩니다!

**배틀 옵션:**
- **공격**: 피카츄의 기술로 공격합니다
- **도구**: 아이템을 사용합니다 (현재 비활성화)
- **포켓몬 교체**: 다른 포켓몬으로 교체합니다 (현재 비활성화)
- **도망**: 전투에서 도망칩니다 (50% 확률)

### 출현 포켓몬

다음 야생 포켓몬들을 만날 수 있습니다:
- 꼬렛 (노말 타입)
- 구구 (노말 타입)
- 캐터피 (벌레 타입)
- 뿔충이 (벌레 타입)
- 참새 (비행 타입)

## 게임 정보

### 시작 포켓몬
- **피카츄** Lv.5
  - HP: 35
  - 기술: 전기충격, 몸통박치기, 꼬리흔들기, 울음소리

### 맵 요소
- 🟩 **연한 초록**: 일반 풀 (통과 가능)
- 🟢 **진한 초록**: 긴 풀 (야생 포켓몬 출현!)
- 🟫 **갈색**: 길 (안전한 이동)
- 🟫 **나무**: 나무 (통과 불가)
- 🔵 **파랑**: 물 (통과 불가)
- 🏠 **집**: 건물 (통과 불가)

## 기술 정보

이 게임은 다음 기술로 만들어졌습니다:
- HTML5 Canvas
- JavaScript (ES6+)
- CSS3

## 게임 시스템

### 전투 시스템
- 턴제 전투
- HP 시스템
- 데미지 계산 (레벨, 공격력, 방어력 기반)
- 타입 상성 시스템 (간단 버전)

### 경험치 시스템
- 야생 포켓몬 처치 시 경험치 획득
- 전투 승리 시 HP 회복 (5 HP)
